# Tau2 rendering templates

Frozen Telecom and Retail system prompts and tool schemas used to render the released candidate turns with each model's native chat template.

The [transfer runner](../README.md) loads these templates by default. Alternative template directories can be configured through the environment variables in the [project README](../../../../README.md).

These templates originate from [tau2-bench](https://github.com/sierra-research/tau2-bench), Copyright (c) 2025 Sierra Research, and retain its [MIT license](LICENSE).

The trajectory candidate turns are distributed in the [Hugging Face dataset](https://huggingface.co/datasets/XijieGong/MI4ToolCalling).
